# بحساب

ربات تلگرام و Telegram Mini App فارسی برای مدیریت حساب‌های مالی دونفره و هزینه‌های شخصی.

## امکانات

- دوستی فقط پس از تأیید طرف مقابل
- حساب مستقل برای هر دوست، بدون گروه
- ثبت بدهی، پرداخت و تسویه با محاسبه خودکار مانده
- ویرایش و حذف تراکنش توسط ثبت‌کننده
- هزینه‌های شخصی مستقل
- تاریخ و تقویم شمسی با منطقه زمانی تهران
- اعلان تلگرام برای درخواست‌ها و تغییرات مالی
- احراز هویت امن با `initData` تلگرام
- رابط کاملاً فارسی، راست‌چین و موبایل‌محور

## اجرای محلی

به Python 3.12 نیاز دارید:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
DEMO_MODE=true uvicorn app.main:app --reload
```

سپس `http://127.0.0.1:8000/?demo=1` را باز کنید. در حالت آزمایشی می‌توانید با تغییر مقدار `localStorage.demoUser` بین کاربران `900001`، `900002` و `900003` جابه‌جا شوید.

## استقرار روی Render

1. کل محتویات این پوشه را در ریشه مخزن GitHub قرار دهید؛ فایل `requirements.txt` باید دقیقاً در ریشه باشد.
2. در Render گزینه **New → Blueprint** را انتخاب و مخزن را متصل کنید.
3. Render با فایل `render.yaml` یک Web Service و یک PostgreSQL Database می‌سازد.
4. در Environment سرویس، مقدار `BOT_TOKEN` را از BotFather وارد کنید.
5. مقدار `APP_URL` را برابر نشانی کامل سرویس قرار دهید؛ برای نمونه `https://behesab-miniapp.onrender.com`.
6. مقدار `DEMO_MODE` باید روی `false` باقی بماند.
7. یک بار Manual Deploy انجام دهید. برنامه Webhook ربات را خودکار تنظیم می‌کند.

پس از استقرار، در BotFather از مسیر `/mybots` → ربات → **Bot Settings** → **Menu Button** نیز همان `APP_URL` را قرار دهید. پیام `/start` به‌صورت خودکار دکمه شیشه‌ای «🚀 ورود به بحساب» را نمایش می‌دهد.

## متغیرهای محیطی

| نام | کاربرد |
|---|---|
| `BOT_TOKEN` | توکن دریافتی از BotFather |
| `APP_URL` | آدرس HTTPS سرویس Render بدون اسلش انتهایی |
| `DATABASE_URL` | خودکار از دیتابیس Render دریافت می‌شود |
| `WEBHOOK_SECRET` | توسط Render ساخته می‌شود |
| `DEMO_MODE` | فقط برای تست محلی؛ در تولید `false` |

## نکته‌های مهم

- هر دو کاربر باید حداقل یک بار ربات را `/start` کنند تا بتوانند یکدیگر را با نام کاربری پیدا کنند.
- ویرایش و حذف فقط برای کاربری مجاز است که تراکنش را ثبت کرده است.
- اطلاعات مالی در PostgreSQL ذخیره می‌شود و با خواب سرویس رایگان از بین نمی‌رود.
- همه پیام‌های ربات دارای دکمه ورود به Mini App هستند.
